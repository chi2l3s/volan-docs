Вложенные записи позволяют создавать или привязывать связанные записи в рамках одного вызова `create`, без ручного прокидывания внешних ключей и без нескольких запросов. Volan оборачивает все вложенные операции в одну транзакцию, так что либо всё успешно, либо ничего не изменяется.

<Note>
  Вложенные записи доступны только внутри `create {}`. Операция `createMany` их **не** поддерживает — попытка вложенной записи внутри `row {}` бросает `VolanValidationException`.
</Note>

## Три операции вложенных записей

Связанную запись внутри `create` можно обработать тремя способами:

| Операция | Поведение |
| --- | --- |
| `relation.create {}` | Создаёт новую связанную запись и привязывает её к родителю. |
| `relation.connect {}` | Привязывает уже существующую запись к родителю по уникальному фильтру. |
| `relation.connectOrCreate {}` | Привязывает существующую запись, если она найдена, иначе создаёт новую. |

## `create` — вставка связанной записи

Вызовите `.create {}` на поле-связи, чтобы создать новую дочернюю запись вместе с родительской. Значения полей для новой связанной записи передаются прямо внутри блока.

### Связь один-к-одному

```kotlin
val user = db.user.create {
    email = "alice@acme.com"
    name  = "Alice"
    profile.create {
        bio = "Software engineer"
    }
}
// `user.profile` заполнен только что созданным Profile
```

### Связь один-ко-многим

```kotlin
val user = db.user.create {
    email = "alice@acme.com"
    name  = "Alice"
    posts.create {
        title = "Hello World"
        body  = "My first post"
    }
}
// Новый Post автоматически привязывается к `user` через внешний ключ
```

Можно сцеплять несколько вызовов `.create {}`, чтобы вставить сразу несколько связанных записей:

```kotlin
val user = db.user.create {
    email = "alice@acme.com"
    name  = "Alice"
    posts.create { title = "Post One";   body = "..." }
    posts.create { title = "Post Two";   body = "..." }
    posts.create { title = "Post Three"; body = "..." }
}
```

## `connect` — привязка существующей записи

Вызовите `.connect {}` на поле-связи, когда связанная запись уже существует и вы просто хотите установить связь. Фильтр внутри `.connect {}` должен соответствовать уникальной строке.

```kotlin
val post = db.post.create {
    title  = "Using Volan"
    author.connect { id eq 42 }   // привязать к существующему User с id = 42
}
```

<Tip>
  `.connect {}` только выставляет колонку внешнего ключа в новой записи — саму связанную запись он не трогает. Если нужно одновременно обновить связанную запись, сделайте это отдельным вызовом `update` внутри [транзакции](/ru/writing/transactions).
</Tip>

## `connectOrCreate` — привязать, если есть, или создать

`.connectOrCreate {}` комбинирует поиск с вставкой-запаской. Вы указываете поля, по которым идентифицируется связанная запись: если совпадение найдено, она привязывается, иначе Volan сначала создаёт запись, а затем привязывает.

Это особенно полезно для связей **многие-ко-многим**, где связанная запись (например, тег) может ещё не существовать.

```kotlin
val post = db.post.create {
    title  = "Tagged Post"
    author.connect { id eq 1 }
    tags.connectOrCreate { name = "kotlin" }
    tags.connectOrCreate { name = "orm" }
}
```

В этом примере если `Tag` с `name = "kotlin"` уже существует, он привязывается к посту; если нет, Volan сначала создаёт его и только затем привязывает. Обе операции выполняются в той же транзакции, что и внешний `create`.

<Note>
  Поля, указанные в `.connectOrCreate {}`, должны покрывать как минимум один уникальный ключ связанной модели, чтобы Volan мог определить, какую строку искать. Если ни один уникальный ключ не покрыт, Volan бросает `VolanValidationException` ещё до отправки SQL.
</Note>

## Комбинация вложенных операций

Можно смешивать `.create`, `.connect` и `.connectOrCreate` на разных полях-связях в одном вызове `create`:

```kotlin
val post = db.post.create {
    title  = "Comprehensive Post"

    // Подключение к существующему автору
    author.connect { id eq 1 }

    // Создание новой Category внутри записи
    category.create { name = "Engineering" }

    // connectOrCreate для нескольких тегов
    tags.connectOrCreate { name = "volan" }
    tags.connectOrCreate { name = "kotlin" }
}
```

## Атомарность

Все операции во вложенной записи — верхнеуровневая запись и каждый вложенный `.create`, `.connect` или `.connectOrCreate` — выполняются в одной транзакции базы. Если любая часть завершается ошибкой (например, фильтр `.connect {}` не нашёл строку), вся операция откатывается, и частичные данные не сохраняются.

<Note>
  Оборачивать вложенную запись в явный блок `db.transaction {}` для этой гарантии не нужно — Volan управляет транзакцией автоматически. Если вы хотите объединить вложенную запись с другими операциями в одной границе транзакции, можно всё равно вложить её внутрь ручного `db.transaction {}`.
</Note>
