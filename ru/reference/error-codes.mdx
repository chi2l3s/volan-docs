Компилятор схемы Volan выводит структурированные диагностики при любой проблеме в вашем файле `.volan`. У каждой диагностики есть уникальный код, человеческое сообщение и местоположение в источнике. На этой странице перечислены все коды по фазам компиляции.

Диагностики имеют формат, похожий на Rust: код и сообщение в первой строке, затем указатель на файл/строку/колонку и встроенная аннотация:

```text
error[E0104]: field declaration is missing its type
  --> schema.volan:12:5
   |
12 |   name
   |   ^^^^ expected a type here, e.g. `name String`
```

## Ошибки лексера (E000x)

Ошибки лексера возникают до парсинга. Компилятор не может токенизировать вход и не пытается продолжать.

<Accordion title="E0001 — UNTERMINATED_STRING">
  **Причина:** Строковый литерал, открытый `"`, не закрыт до конца строки.

  **Исправление:** Закройте строку на той же строке.
</Accordion>

<Accordion title="E0002 — INVALID_ESCAPE_SEQUENCE">
  **Причина:** Строковый литерал содержит обратный слэш и символ, который не является распознаваемым escape (`\n`, `\t`, `\\`, `\"`, `\r`).

  **Исправление:** Используйте допустимый escape или уберите обратный слэш.
</Accordion>

<Accordion title="E0003 — UNEXPECTED_CHARACTER">
  **Причина:** Лексер встретил символ, недопустимый в схеме Volan (`$`, `%`, голый `#` и т.п.).

  **Исправление:** Уберите или замените символ. Для комментариев используйте `//`.
</Accordion>

<Accordion title="E0004 — BLOCK_COMMENT_NOT_SUPPORTED">
  **Причина:** Найден блочный комментарий `/* … */`. Volan поддерживает только строчные (`//`) и док-комментарии (`///`).

  **Исправление:** Замените на строчные комментарии.
</Accordion>

<Accordion title="E0005 — MALFORMED_NUMBER">
  **Причина:** Числовой литерал не удалось разобрать — например, `1_` (висячее подчёркивание), `0x` (неполный hex) или `1.2.3`.

  **Исправление:** Исправьте литерал до корректного целого или числа с плавающей точкой.
</Accordion>

## Ошибки парсера (E01xx)

Ошибки парсера возникают, когда поток токенов не соответствует ожидаемой грамматике. Volan пытается восстановиться и может вывести несколько ошибок за один проход.

| Код | Имя | Описание |
| --- | --- | --- |
| `E0100` | `EXPECTED_DECLARATION` | Ожидалось ключевое слово верхнего уровня (`model`, `enum`, `datasource`, `generator`) |
| `E0101` | `EXPECTED_NAME` | Найдено ключевое слово, но за ним нет идентификатора |
| `E0102` | `EXPECTED_OPENING_BRACE` | Нет `{` после имени объявления |
| `E0103` | `UNCLOSED_BLOCK` | Блок открыт `{`, но не закрыт `}` |
| `E0104` | `EXPECTED_FIELD_TYPE` | После имени поля в модели не указан тип |
| `E0105` | `EXPECTED_EQUALS` | В блоке `datasource`/`generator` отсутствует `=` между ключом и значением |
| `E0106` | `EXPECTED_EXPRESSION` | Ожидалось выражение, но нет корректного значения |
| `E0107` | `UNCLOSED_ARGUMENT_LIST` | Список аргументов атрибута открыт `(`, но не закрыт `)` |
| `E0108` | `UNCLOSED_LIST` | Литерал массива `[…]` не закрыт |
| `E0109` | `OPTIONAL_LIST_TYPE` | Записано `Type[]?` — списочные поля не могут быть необязательными |
| `E0110` | `NESTED_LIST_TYPE` | Вложенный список `Type[][]` не поддерживается |
| `E0111` | `REPEATED_OPTIONAL_MARKER` | Записано `??` вместо `?` |
| `E0112` | `WRONG_ATTRIBUTE_FORM` | Атрибут поля `@attr` использован там, где требуется атрибут модели `@@attr`, или наоборот |
| `E0113` | `EXPECTED_ATTRIBUTE_NAME` | Голый `@` без идентификатора |
| `E0114` | `EXPECTED_ATTRIBUTE_MEMBER` | Префикс `@ns.` без имени члена |
| `E0115` | `EXPECTED_ARGUMENT_VALUE` | Именованный аргумент `name:` без значения |
| `E0116` | `UNEXPECTED_TOP_LEVEL_TOKEN` | На верхнем уровне найден недопустимый токен |
| `E0117` | `EMPTY_MODEL` | Блок `model` не содержит полей |
| `E0118` | `EMPTY_ENUM` | Блок `enum` не содержит значений |
| `E0119` | `EXPECTED_CONFIGURATION_VALUE` | Какой-либо ключ конфига в `datasource`/`generator` без значения |
| `E0120` | `ATTRIBUTE_NOT_ALLOWED_HERE` | Атрибут в контексте, где он не допускается |
| `E0121` | `UNEXPECTED_TOKEN_IN_BLOCK` | Недопустимый токен внутри текущего блока |

## Семантические ошибки (E02xx)

Семантические ошибки сообщаются после успешного разбора схемы: логические или типовые несогласованности.

### Объявления и именование

| Код | Имя | Описание |
| --- | --- | --- |
| `E0200` | `DUPLICATE_DECLARATION` | Два объявления верхнего уровня имеют одинаковое имя |
| `E0201` | `UNKNOWN_TYPE` | Тип поля не является скаляром, перечислением или моделью |
| `E0202` | `DUPLICATE_MEMBER` | Два поля модели или два значения перечисления совпадают по имени |

### Конфигурация Datasource и Generator

| Код | Имя | Описание |
| --- | --- | --- |
| `E0203` | `MISSING_DATASOURCE` | Нет блока `datasource` |
| `E0204` | `DUPLICATE_DATASOURCE` | Более одного блока `datasource` |
| `E0205` | `UNKNOWN_PROVIDER` | Неизвестный провайдер базы |
| `E0206` | `MISSING_OPTION` | Отсутствует обязательное свойство |
| `E0207` | `UNKNOWN_OPTION` | Неизвестное свойство |
| `E0208` | `INVALID_OPTION_VALUE` | Свойство имеет значение неверного вида |

### Идентичность и первичные ключи

| Код | Имя | Описание |
| --- | --- | --- |
| `E0209` | `MISSING_PRIMARY_KEY` | Модель без первичного ключа |
| `E0210` | `DUPLICATE_PRIMARY_KEY` | Первичный ключ объявлен дважды |
| `E0211` | `INVALID_ID_FIELD` | Поле не может быть частью первичного ключа |

### Атрибуты

| Код | Имя | Описание |
| --- | --- | --- |
| `E0212` | `UNKNOWN_ATTRIBUTE` | Неизвестное имя атрибута |
| `E0213` | `UNKNOWN_ATTRIBUTE_ARGUMENT` | Недопустимый аргумент атрибута |
| `E0214` | `MISSING_ATTRIBUTE_ARGUMENT` | Отсутствует обязательный аргумент |
| `E0215` | `INVALID_ATTRIBUTE_TARGET` | Атрибут нельзя применить к этому полю/блоку |
| `E0216` | `DUPLICATE_ATTRIBUTE` | Один и тот же атрибут применён больше одного раза |
| `E0231` | `UNKNOWN_ATTRIBUTE_NAMESPACE` | Нативный атрибут использует не `db` пространство имён |

### Значения по умолчанию и ограничения

| Код | Имя | Описание |
| --- | --- | --- |
| `E0217` | `INVALID_DEFAULT` | `@default` не подходит полю |
| `E0218` | `INVALID_UPDATED_AT` | `@updatedAt` на поле, не являющемся `DateTime` |
| `E0229` | `INVALID_UNIQUE_FIELD` | `@unique` на недопустимом поле |
| `E0230` | `EMPTY_FIELD_LIST` | Ограничение `@@unique`/`@@index` на пустом списке полей |

### Связи

| Код | Имя | Описание |
| --- | --- | --- |
| `E0219` | `UNKNOWN_FIELD_REFERENCE` | Атрибут ссылается на несуществующее поле |
| `E0220` | `RELATION_MISSING_OPPOSITE` | У связи нет парного поля на другой модели |
| `E0221` | `RELATION_AMBIGUOUS` | Несколько полей связи могут составить пару |
| `E0222` | `RELATION_ARGUMENT_MISMATCH` | `fields:` и `references:` в `@relation` не согласуются |
| `E0223` | `RELATION_INVALID_SIDE` | Внешний ключ объявлен не на той стороне, на обеих или ни на одной |
| `E0224` | `RELATION_REFERENCE_NOT_UNIQUE` | `references:` не идентифицирует строку |
| `E0225` | `RELATION_TYPE_MISMATCH` | Типы внешнего ключа и целевого поля различаются |
| `E0226` | `INVALID_REFERENTIAL_ACTION` | Референциальное действие невозможно для этой связи |
| `E0232` | `UNSATISFIABLE_REQUIRED_RELATION` | Модель требует строку самой себя |
| `E0233` | `RELATION_FOREIGN_KEY_NOT_UNIQUE` | Внешний ключ связи один-к-одному не уникален |

### Сопоставленные имена

| Код | Имя | Описание |
| --- | --- | --- |
| `E0227` | `DUPLICATE_MAPPED_NAME` | Две модели или поля отображаются в одно и то же имя в базе |

## Предупреждения

Предупреждения не мешают генерации кода, но указывают на паттерны, которые стоит исправить.

<Accordion title="W0001 — DANGLING_DOC_COMMENT">
  **Причина:** Комментарий `///` не прикреплён ни к какому объявлению.

  **Исправление:** Привяжите его к модели, полю или варианту перечисления или превратите в обычный `//`.
</Accordion>

<Accordion title="E0234 — CONNECTION_URL_IN_SCHEMA">
  **Причина:** В схеме прямо вписан URL базы с учётными данными, которые могут попасть в VCS.

  **Исправление:** Вынесите URL в переменную окружения и ссылайтесь через `env()`.
</Accordion>

<Accordion title="E0228 — CASCADE_CYCLE">
  **Причина:** Цепочка `onDelete: Cascade` образует цикл. Допускается, но может привести к неожиданному поведению в рантайме.

  **Исправление:** Пересмотрите референциальные действия и соблюдите `Restrict` или `SetNull`, чтобы разорвать цикл.
</Accordion>
