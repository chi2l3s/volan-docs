Перечисления позволяют задать фиксированный набор именованных значений и использовать их как типы полей в моделях. Volan хранит значения перечислений в базе данных как строки и генерирует `enum class` на Kotlin, который автоматически выполняет сериализацию и десериализацию. Вы можете точно управлять тем, какая строка запишется в базу, не затрагивая имена в Kotlin.

## Базовый синтаксис перечисления

Объявите перечисление ключевым словом `enum`, именем в PascalCase и одним или несколькими значениями в ALL\_CAPS:

```prisma
enum Role {
  USER
  ADMIN
  MODERATOR
}
```

После этого `Role` можно использовать как тип поля в любой модели:

```prisma
model User {
  id   Int    @id @default(autoincrement())
  role Role   @default(USER)
}
```

## Сопоставление значений с произвольными строками в базе

По умолчанию Volan хранит каждое значение под его объявленным именем (например, `"USER"`, `"ADMIN"`). Чтобы переопределить это, используйте `@map` на отдельных значениях:

```prisma
enum Role {
  USER
  ADMIN      @map("administrator")
  MODERATOR  @map("mod")
}
```

При таком объявлении константа Kotlin `ADMIN` хранится в базе как `"administrator"`, а `MODERATOR` — как `"mod"`. На имена констант в Kotlin это не влияет — в коде приложения вы всегда используете `Role.ADMIN`.

## Сопоставление самого перечисления с другим именем типа

Используйте `@@map` на блоке перечисления, чтобы задать имя типа в базе данных (это важно для нативных enum в PostgreSQL и полезно для документации в других СУБД):

```prisma
enum Role {
  USER
  ADMIN @map("administrator")

  @@map("user_role")
}
```

## Сгенерированный код Kotlin

Volan генерирует `enum class` на Kotlin со свойством `databaseValue` у каждой константы и фабрикой `fromDatabaseValue()` в companion-объекте:

```kotlin
enum class Role(val databaseValue: String) {
    USER("USER"),
    ADMIN("administrator"),
    MODERATOR("mod");

    companion object {
        fun fromDatabaseValue(value: String): Role =
            entries.first { it.databaseValue == value }
    }
}
```

| Элемент | Описание |
| --- | --- |
| `databaseValue: String` | Строковое значение, которое записывается в колонку базы и читается из неё |
| `fromDatabaseValue(value)` | Находит константу перечисления, чей `databaseValue` совпадает с переданной строкой; бросает `NoSuchElementException`, если не нашла |

Когда Volan читает строку из базы, он вызывает `fromDatabaseValue()` автоматически. Вызывать его напрямую нужно только при работе с результатами сырых запросов.

## Перечисления как значения по умолчанию

Передайте значение перечисления (без префикса класса) в `@default`, чтобы задать значение колонки по умолчанию:

```prisma
model User {
  id   Int  @id @default(autoincrement())
  role Role @default(USER)
}
```

Значение по умолчанию применяется на уровне базы данных как сопоставленная строка (в данном случае `"USER"`), а также поддерживается сгенерированным клиентом при вставке записи без явного `role`.

<Note>
  Значение, переданное в `@default`, должно быть одной из констант перечисления, объявленных в схеме — Volan проверяет это при разборе схемы и сообщит об ошибке при несовпадении.
</Note>

## Док-комментарии к перечислениям

Используйте док-комментарии `///` на объявлениях перечислений и отдельных значениях, чтобы перенести документацию в сгенерированный код Kotlin:

```prisma
/// Роль доступа, назначенная учётной записи пользователя.
enum Role {
  /// Обычный аутентифицированный пользователь.
  USER
  /// Полный административный доступ.
  ADMIN @map("administrator")
}
```

Сгенерированный enum-класс и его константы получат соответствующие комментарии KDoc.

## Полный пример

```prisma
/// Роль доступа, назначенная учётной записи пользователя.
enum Role {
  USER
  ADMIN      @map("administrator")
  MODERATOR  @map("mod")

  @@map("user_role")
}

model User {
  id   Int    @id @default(autoincrement())
  role Role   @default(USER)

  @@map("users")
}
```

Сгенерированный Kotlin:

```kotlin
/** Роль доступа, назначенная учётной записи пользователя. */
enum class Role(val databaseValue: String) {
    /** Обычный аутентифицированный пользователь. */
    USER("USER"),
    /** Полный административный доступ. */
    ADMIN("administrator"),
    MODERATOR("mod");

    companion object {
        fun fromDatabaseValue(value: String): Role =
            entries.first { it.databaseValue == value }
    }
}
```

<Tip>
  Если в вашей базе уже хранятся строковые значения, отличающиеся от желаемых имён констант в Kotlin, используйте `@map`, а не переименовывайте константы. Так код на Kotlin останется идиоматичным и не потребуется миграция данных.
</Tip>
