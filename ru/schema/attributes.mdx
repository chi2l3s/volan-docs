Атрибуты — это аннотации, которые вы прикрепляете к полям или блокам моделей, чтобы настроить поведение: первичные ключи, ограничения, значения по умолчанию, имена колонок и определения индексов. Атрибуты уровня поля используют одинарный префикс `@`; атрибуты уровня блока — `@@` и располагаются внизу тела модели. Эта страница — полный справочник по всем атрибутам, которые поддерживает Volan.

## Атрибуты уровня поля (`@`)

Атрибуты уровня поля пишутся в той же строке, что и объявление поля, после типа.

### `@id`

Объявляет поле первичным ключом таблицы. У каждой модели должно быть ровно одно поле с `@id` либо один блочный атрибут `@@id`.

```prisma
model Product {
  id Int @id @default(autoincrement())
}
```

Для каждой модели с однополевым первичным ключом Volan генерирует метод `findById`.

---

### `@default(value)`

Задаёт значение колонки по умолчанию. Значением может быть вызов функции или литерал:

| Выражение | Используется с | Эффект |
| --- | --- | --- |
| `autoincrement()` | `Int`, `Long` | Последовательность автоинкремента в базе |
| `now()` | `DateTime` | Текущая метка времени при вставке |
| Числовой литерал | `Int`, `Long`, `Float`, `Double`, `Decimal` | Фиксированное числовое значение |
| Строковый литерал | `String` | Фиксированная строка |
| Логический литерал | `Boolean` | `true` или `false` |
| Значение перечисления | Любой тип enum | Значение из указанного перечисления |

```prisma
model Order {
  id        Int      @id @default(autoincrement())
  status    Status   @default(PENDING)
  total     Decimal  @default(0)
  note      String   @default("")
  active    Boolean  @default(true)
  createdAt DateTime @default(now())
}
```

---

### `@unique`

Создаёт уникальный индекс на этом поле и генерирует в клиенте удобный метод `findByFieldName`.

```prisma
model User {
  id    Int    @id @default(autoincrement())
  email String @unique
  slug  String @unique
}
```

---

### `@updatedAt`

Указывает клиенту Volan устанавливать это поле в текущую метку времени при каждом `UPDATE`. Поле должно иметь тип `DateTime`.

```prisma
model Post {
  id        Int      @id @default(autoincrement())
  updatedAt DateTime @updatedAt
}
```

<Note>
  `@updatedAt` применяется в сгенерированном коде клиента, а не как триггер базы данных. Если вы обновляете строки в обход клиента Volan, это поле автоматически обновляться не будет.
</Note>

---

### `@map("column_name")`

Сопоставляет поле с колонкой базы данных, имеющей другое имя. Имя свойства в Kotlin остаётся прежним; меняется только имя колонки в SQL.

```prisma
model User {
  createdAt DateTime @default(now()) @map("created_at")
  updatedAt DateTime @updatedAt      @map("updated_at")
}
```

---

### `@ignore`

Исключает поле из сгенерированного клиента. Колонка остаётся в схеме базы данных — Volan просто не читает и не пишет в неё.

```prisma
model User {
  id           Int    @id @default(autoincrement())
  passwordHash String @ignore
}
```

<Warning>
  Поскольку поля с `@ignore` исключаются из запросов `SELECT`, они не появятся в экземплярах модели, даже если в базе у них есть непустое значение.
</Warning>

---

### `@relation(...)`

Определяет связь между моделями. Полное описание см. в разделе [Связи](/ru/schema/relations). Параметры:

| Параметр | Тип | Описание |
| --- | --- | --- |
| `fields` | `[fieldName, ...]` | Поле (поля) внешнего ключа в этой модели |
| `references` | `[fieldName, ...]` | Соответствующее поле (поля) в целевой модели |
| `onDelete` | `Cascade \| SetNull \| Restrict \| NoAction` | Действие при удалении целевой строки |
| `onUpdate` | `Cascade \| SetNull \| Restrict \| NoAction` | Действие при изменении ключа целевой строки |

```prisma
model Post {
  author   User @relation(fields: [authorId], references: [id], onDelete: Cascade)
  authorId Int
}
```

---

### `@db.*`

Передаёт движку миграций подсказку о типе, специфичную для провайдера. Это управляет точным типом колонки в DDL, не влияя на соответствие типов в Kotlin.

```prisma
model User {
  email   String  @db.VarChar(320)
  bio     String  @db.Text
  score   Decimal @db.Decimal(10, 2)
}
```

Доступные подсказки зависят от активного провайдера в `datasource`. Volan проверяет их на соответствие провайдеру на этапе миграции.

## Атрибуты уровня блока (`@@`)

Атрибуты уровня блока располагаются внутри тела модели, по соглашению внизу, и влияют на таблицу целиком.

### `@@id([field1, field2])`

Объявляет составной первичный ключ по нескольким полям. Не используйте `@id` ни на одном из перечисленных полей.

```prisma
model OrderItem {
  orderId   Int
  productId Int
  quantity  Int

  @@id([orderId, productId])
}
```

---

### `@@unique([field1, field2])`

Создаёт составное уникальное ограничение. Полезно, когда уникальность охватывает несколько колонок.

```prisma
model Membership {
  userId Int
  orgId  Int

  @@unique([userId, orgId])
}
```

---

### `@@index([field1, field2])`

Создаёт составной индекс для ускорения запросов с фильтрацией или сортировкой по нескольким колонкам. На одной модели можно объявить несколько блоков `@@index`.

```prisma
model Post {
  id          Int      @id @default(autoincrement())
  authorId    Int
  publishedAt DateTime

  @@index([authorId, publishedAt])
}
```

---

### `@@map("table_name")`

Сопоставляет модель с таблицей базы данных, имеющей другое имя. Имя класса в Kotlin не меняется.

```prisma
model User {
  id Int @id @default(autoincrement())

  @@map("users")
}
```

---

### `@@fulltext([field1, field2])`

Создаёт индекс полнотекстового поиска по перечисленным полям. Поддерживается в PostgreSQL (с `pg_trgm`) и MySQL.

```prisma
model Article {
  id    Int    @id @default(autoincrement())
  title String
  body  String

  @@fulltext([title, body])
}
```

<Warning>
  `@@fulltext` не поддерживается в SQLite. Использование с провайдером `sqlite` вызывает ошибку валидации схемы.
</Warning>

---

### `@@ignore`

Исключает модель целиком из сгенерированного клиента. Таблица продолжает существовать в базе и всё ещё проверяется Volan, но ни класс, ни методы запросов не генерируются.

```prisma
model LegacyAuditLog {
  id      Int    @id
  payload String

  @@ignore
}
```

## Краткий справочник

### Уровень поля (`@`)

| Атрибут | Ключевые параметры | Эффект |
| --- | --- | --- |
| `@id` | — | Первичный ключ |
| `@default(value)` | выражение или литерал | Значение колонки по умолчанию |
| `@unique` | — | Уникальное ограничение \+ метод `findBy` |
| `@updatedAt` | — | Автоустановка при обновлении (на стороне клиента) |
| `@map("col")` | строка с именем колонки | Переименование колонки в SQL |
| `@ignore` | — | Исключить поле из клиента |
| `@relation(...)` | `fields`, `references`, `onDelete`, `onUpdate` | Определение связи |
| `@db.*` | тип провайдера | Подсказка типа колонки для провайдера |

### Уровень блока (`@@`)

| Атрибут | Ключевые параметры | Эффект |
| --- | --- | --- |
| `@@id([...])` | список полей | Составной первичный ключ |
| `@@unique([...])` | список полей | Составное уникальное ограничение |
| `@@index([...])` | список полей | Составной индекс |
| `@@map("table")` | строка с именем таблицы | Переименование таблицы в SQL |
| `@@fulltext([...])` | список полей | Индекс полнотекстового поиска |
| `@@ignore` | — | Исключить модель из клиента |
